# Interface design

The code graph contains multiple components for the web interface.

![Code node interfaces](/images/code-graph-main.png)

## Layout

The layout has a clear concept of web interface as it is shown in a drawing:

![Code node interfaces](/images/code-graph-layout.png)

| Component | Description | Location |
| --------- | ----------- | -------- |
| Toolbar | A group of button for the graph | top |
| Node Palette | A list of node types to add | left |
| Code Editor | A editor view for code script | right |
| Graph Editor | A workspace for code graph | center |
