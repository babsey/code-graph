---
title: Available Scripts
subject: Tutorial
---


| Script  | Command            | Description                                             |
| ------- | ------------------ | ------------------------------------------------------- |
| dev     | ```yarn dev```     | Start the Vite dev server with HMR                      |
| build   | ```yarn build```   | Type-check and build for production                     |
| preview | ```yarn preview``` | Serve the production build locally                      |
| lint    | ```yarn lint```    | Lint source files with ESLint                           |
| format  | ```yarn format```  | Auto-formats indentation, quotes, trailing commas, etc. |
