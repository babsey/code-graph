# Basic usage

Visiting `localhost:5173` you will see the main page of Code Graph. 

![Main page](/images/code-graph-main.png)

## Layout

The layout is composed of toolbar buttons (top), palette for node types (left), code graph view (center) and code editor (right).

![Layout](/images/code-graph-layout.png)

### Toolbar buttons

The toolbar contains icon buttons for various command executions.

### Palette for node types

The palette contains a list of registered node types. 
The user can drag the selected node type to the graph editor to create a new node.

### Graph editor

The graph editor visualizes nodes and connections.

### Code editor

The code editor displays the generated code which are rendered from the code nodes. 
It also allows users to edit the code value.
